# 📊Sales-Analysis
This repo a quick analysis of sales performance of a business.

## 🛠 Tools used 
- Google Sheets
- PowerBi

## 📈 Project Overview
This is a personal project that uses an interactive PowerBi dashboard analysing 8,399 sales transactions from 2014 to 2017. It uses a star-schema data model and DAX measures to answer questions about revenue, orders, seasonality, sales team performance, shipping and product mix.

## 📂 Project Structure
- /data – Contains the raw dataset and cleaned/split CSV files used in this project.
- /analysis – Includes PNG charts generated during analysis.
- /screenshots – Screenshots of pivot tables and spreadsheet transformations.
- insights.md – Markdown summary of all key insights extracted from the analysis.
- README.md – This file you’re reading now!

## 🎯 Business questions answered
- How much revenue does the business generate, and from how many orders?
- Is revenue growing or declining year over year?
- Are there seasonal patterns that should shape planning?
- Which salesperson contributes the most, and is performance balanced?
- Which shipping methods do customers rely on?
- Does order priority influence revenue?
- Which product containers drive the most sales?

## ✅ Key Insight (Summary)
1. Revenue fell after 2014 and only partly recovered. 2014 peaked at about $4.1M, dropped roughly 15% in 2015, bottomed out in 2016, then rebounded about 8% in 2017 to $3.7M.
2. Clear seasonality. Revenue peaks in January and December (about $1.4M each) and dips in June (about $1.0M). Peak months run roughly 40% above the low point.
3. Balanced sales team. Bob leads at about $5.0M, but John and Richard are within about 4%, so there is no dependence on a single top performer.
4. Concentrated shipping. Regular Air (about 51%) and Delivery Truck (about 41%) account for most revenue. Express Air is only about 8%.
5. A few containers dominate. Small Box alone is about 35% of revenue, and the top three containers make up roughly three-quarters.
6. Order priority has little effect. Revenue is spread fairly evenly across priority levels.

## 📝 Recommendations
- Run a mid-year promotion to offset the June slump.
- Plan inventory and staffing around the December/January peak.
- Review low-performing containers (Wrap Bag, Small Pack) for repricing or removal.
- Test whether Express Air can be grown or whether it should stay a niche option.
